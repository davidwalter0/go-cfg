* Migration Guide Overview

This guide shows how to migrate from the legacy =github.com/davidwalter0/go-cfg= library to the new v3 unified module architecture.

** Migration Strategy: Complete Backward Compatibility

The v3 module provides **complete backward compatibility** through the legacy compatibility layer while offering enhanced modern features.

* Migration Options

** Option 1: Zero-Change Migration (Recommended for Quick Migration)

Replace your import with the legacy compatibility layer:

#+begin_src go
// Old import
import "github.com/davidwalter0/go-cfg"

// New import (zero code changes required)
import legacy "github.com/davidwalter0/go-cfg/v3/legacy"
#+end_src

All existing code continues to work exactly as before:

#+begin_src go
var cfg AppConfig
if err := legacy.Init(&cfg); err != nil {
    log.Fatalf("Configuration failed: %v", err)
}
#+end_src

** Option 2: Modern v3 API Migration (Recommended for New Features)

Migrate to the modern v3 API for enhanced capabilities:

#+begin_src go
import "github.com/davidwalter0/go-cfg/v3/pkg/config"

var cfg AppConfig
if err := config.Load(&cfg); err != nil {
    log.Fatalf("Configuration failed: %v", err)
}
#+end_src

** Option 3: Hybrid Approach (Best of Both Worlds)

Use legacy compatibility for existing code, modern API for new features:

#+begin_src go
import (
    legacy "github.com/davidwalter0/go-cfg/v3/legacy"
    "github.com/davidwalter0/go-cfg/v3/pkg/config"
)

// Existing legacy code
if err := legacy.Init(&legacyCfg); err != nil {
    return err
}

// New modern code with enhanced features
manager := config.NewManager().
    WithDiscovery(config.Union | config.Direct).
    WithFlagStyle(config.FlatNest).
    WithValidation(true)

if err := manager.Load(&modernCfg); err != nil {
    return err
}
#+end_src

* Migration Examples

** Basic Configuration Migration

*** Before (Legacy)
#+begin_src go
package main

import (
    "log"
    cfg "github.com/davidwalter0/go-cfg"
)

type Config struct {
    ServiceName string `json:"service_name" default:"my-service"`
    Port        int    `json:"port" default:"8080"`
}

func main() {
    var config Config
    if err := cfg.Init(&config); err != nil {
        log.Fatalf("Configuration failed: %v", err)
    }
    
    log.Printf("Service: %s, Port: %d", config.ServiceName, config.Port)
}
#+end_src

*** After (Zero-Change Migration)
#+begin_src go
package main

import (
    "log"
    legacy "github.com/davidwalter0/go-cfg/v3/legacy"  // Only import changed
)

type Config struct {
    ServiceName string `json:"service_name" default:"my-service"`
    Port        int    `json:"port" default:"8080"`
}

func main() {
    var config Config
    if err := legacy.Init(&config); err != nil {  // cfg.Init -> legacy.Init
        log.Fatalf("Configuration failed: %v", err)
    }
    
    log.Printf("Service: %s, Port: %d", config.ServiceName, config.Port)
}
#+end_src

*** After (Modern v3 API)
#+begin_src go

import (
    "log"
    "github.com/davidwalter0/go-cfg/v3/pkg/config"

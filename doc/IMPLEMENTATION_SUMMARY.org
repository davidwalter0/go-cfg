* Key Features

** Automatic Environment Integration

Field names automatically convert to environment variables:

#+BEGIN_SRC go
type Config struct {
    APIEndpoint *types.URLValue      // -> API_ENDPOINT
    DatabaseURL *types.URLValue      // -> DATABASE_URL
    HTTPSProxy  string               // -> HTTPS_PROXY
}
#+END_SRC

** Consistent Naming Conventions

- Go fields: =CamelCase= (=APIEndpoint=)
- Environment variables: =UPPER_SNAKE_CASE= (=API_ENDPOINT=)
- Command-line flags: =kebab-case= (=--api-endpoint=)
- JSON/YAML: =kebab-case= (="api-endpoint"=)

** Type Safety and Validation

All custom types include:

- Optional validation hooks

* Usage Patterns

** Automatic Registration

#+BEGIN_SRC go
type Config struct {
    Name     string              `usage:"App name" default:"myapp"`
    Timeout  *types.DurationValue `usage:"Timeout"`
    LogLevel *types.LogLevelValue  `usage:"Log level"`
}

config := &Config{
    Timeout:  types.NewDurationValue(30 * time.Second),
    LogLevel: types.NewLogLevelValue("info"),
}

flagConfig := flags.NewFlagConfig()
flagConfig.RegisterCustomTypes(config)
flagConfig.Parse(os.Args[1:])
#+END_SRC

** Manual Registration

#+BEGIN_SRC go
flagSet := pflag.NewFlagSet("myapp", pflag.ExitOnError)

var serverURL *types.URLValue
flags.RegisterURLFlag(flagSet, "ServerURL", &serverURL, "Server endpoint")

var logLevel *types.LogLevelValue  
validLevels := []string{"debug", "info", "warn", "error"}
flags.RegisterEnumFlag(flagSet, "LogLevel", &logLevel, validLevels, "info", "Log level")
#+END_SRC

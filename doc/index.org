* Getting Started

1. **Choose Configuration Mode**: Use FlatNest() for most applications
2. **Define Struct**: Create configuration struct with appropriate tags
3. **Parse Configuration**: Call cfg.FlatNest(&config)
4. **Add Help Text**: Provide usage examples and required fields
5. **Handle Config Files**: Load YAML/JSON as needed

* Example Usage

#+begin_src go
type Config struct {
    ServiceName string `required:"true" json:"service_name"`
    API struct {
        Host string `default:"localhost" json:"host"`
        Port int    `default:"8080" json:"port"`
    } `json:"api"`
}

func main() {
    var config Config
    cfg.HelpText("My Application - Configure with --service-name and --api-port")
    if err := cfg.FlatNest(&config); err != nil {
        log.Fatal(err)
    }
    // Use config...
}
#+end_src

This generates clean flags: =--service-name=, =--api-host=, =--api-port=

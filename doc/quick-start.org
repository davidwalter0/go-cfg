* Overview

This guide demonstrates various structural representations and usage patterns for the go-cfg configuration system, focusing on practical examples using the enhanced pkg/flags package.

* Basic Configuration Structures

** Simple Configuration

#+begin_src go :tangle examples/simple-config.go :results org :main no :package discard :mkdirp yes :tangle-mode o0644
package main

import (
	"fmt"
	"os"
	"time"
	
	"github.com/davidwalter0/go-cfg/pkg/flags"
	"github.com/davidwalter0/go-cfg/pkg/flags/types"
)

type SimpleConfig struct {
	Name    string `usage:"Application name" default:"myapp"`
	Port    int    `usage:"Server port" default:"8080"`
	Debug   bool   `usage:"Enable debug mode"`
	Timeout time.Duration `usage:"Request timeout" default:"30s"`
}

func main() {
	config := &SimpleConfig{}
	
	fc := flags.NewFlagConfig()
	if err := fc.RegisterCustomTypes(config); err != nil {
		fmt.Printf("Error: %v\n", err)
		os.Exit(1)
	}
	
	if err := fc.Parse(os.Args[1:]); err != nil {
		fmt.Printf("Parse error: %v\n", err)
		os.Exit(1)
	}
	
	fmt.Printf("Config: %+v\n", config)
}
#+end_src

type EnhancedConfig struct {
	// URLs with validation
	APIEndpoint  *types.URLValue      `usage:"API endpoint URL" default:"https://api.example.com"`
	DatabaseURL  *types.URLValue      `usage:"Database connection URL"`
	
	// Durations with flexible parsing
	Timeout      *types.DurationValue `usage:"Request timeout" default:"30s"`
	KeepAlive    *types.DurationValue `usage:"Keep alive duration" default:"10m"`
	
	// Enums with validation
	LogLevel     *types.LogLevelValue      `usage:"Log level" default:"info"`
	Environment  *types.EnvironmentValue   `usage:"Environment" default:"development"`
	
	// Network types
	ListenAddr   *types.HostPortValue      `usage:"Listen address" default:"localhost:8080"`
	
	// Key-value pairs
	Labels       *types.KeyValueValue      `usage:"Key-value labels"`
}

func NewEnhancedConfig() *EnhancedConfig {
	return &EnhancedConfig{
		APIEndpoint: types.NewURLValue("https://api.example.com"),
		DatabaseURL: types.NewURLValue(""),
		Timeout:     types.NewDurationValue(30 * time.Second),
		KeepAlive:   types.NewDurationValue(10 * time.Minute),
		LogLevel:    types.NewLogLevelValue("info"),
		Environment: types.NewEnvironmentValue("development"),
		ListenAddr:  types.NewHostPortValue("localhost:8080"),
		Labels:      types.NewKeyValueValue(map[string]string{}),
	}
}

type SliceConfig struct {
	// String slices that preserve empty strings

	// Integer slices

type ProductionConfig struct {
	// Basic settings
	ServiceName string               `usage:"Service name" default:"api-service"`
	Environment *types.EnvironmentValue `usage:"Environment" default:"production"`
	Version     string               `usage:"Service version" default:"1.0.0"`
	
	// Network configuration
	ListenAddr  *types.HostPortValue `usage:"Listen address" default:"0.0.0.0:8080"`
	ExternalURL *types.URLValue      `usage:"External service URL"`
	
	// Timing configuration
	Timeouts    []time.Duration      `usage:"Operation timeouts" default:"1s,10s,60s"`
	
	// Resource limits
	MaxConnections int              `usage:"Maximum concurrent connections" default:"1000"`
	WorkerCount    int              `usage:"Worker goroutine count" default:"10"`
	
	// Feature flags
	EnableMetrics bool             `usage:"Enable metrics collection" default:"true"`
	EnableTracing bool             `usage:"Enable distributed tracing"`
	EnableCaching bool             `usage:"Enable response caching" default:"true"`
	
	// Nested configurations
	Security   SecurityConfig       `usage:"Security settings"`
	Monitoring MonitoringConfig     `usage:"Monitoring settings"`
	
	// Labels and metadata
	Labels     *types.KeyValueValue `usage:"Service labels"`
}

func NewProductionConfig() *ProductionConfig {
	return &ProductionConfig{
		Environment: types.NewEnvironmentValue("production"),
		ListenAddr:  types.NewHostPortValue("0.0.0.0:8080"),
		ExternalURL: types.NewURLValue(""),
		Labels:      types.NewKeyValueValue(map[string]string{}),
		Monitoring: MonitoringConfig{
			MetricsAddr:   types.NewHostPortValue("localhost:9090"),
			HealthAddr:    types.NewHostPortValue("localhost:8081"),
			LogLevel:      types.NewLogLevelValue("info"),
			TraceEndpoint: types.NewURLValue(""),
		},
	}
}

* Configuration Loading Patterns

** Complete Example with Error Handling

#+begin_src go :tangle examples/complete-example.go :results org :main no :package discard :mkdirp yes :tangle-mode o0644
package main

import (
	"fmt"
	"log"
	"os"
	
	"github.com/davidwalter0/go-cfg/pkg/flags"
	"github.com/davidwalter0/go-cfg/pkg/flags/types"
)

type AppConfig struct {
	ServiceName string                   `usage:"Service name" default:"myservice"`
	Environment *types.EnvironmentValue  `usage:"Environment" default:"development"`
	ListenAddr  *types.HostPortValue     `usage:"Listen address" default:"localhost:8080"`
	LogLevel    *types.LogLevelValue     `usage:"Log level" default:"info"`
	
	// Slice configurations
	Tags        []string                 `usage:"Service tags"`
	Timeouts    []time.Duration          `usage:"Timeout values" default:"1s,5s,30s"`
	
	// Nested configuration
	Database    DatabaseConfig           `usage:"Database configuration"`
}

type DatabaseConfig struct {
	Host     string `usage:"Database host" default:"localhost"`
	Port     int    `usage:"Database port" default:"5432"`
	Username string `usage:"Database username" default:"user"`
	Password string `usage:"Database password"`
	Database string `usage:"Database name" default:"myapp"`
}

func NewAppConfig() *AppConfig {
	return &AppConfig{
		Environment: types.NewEnvironmentValue("development"),
		ListenAddr:  types.NewHostPortValue("localhost:8080"),
		LogLevel:    types.NewLogLevelValue("info"),
	}
}

func (c *AppConfig) Validate() error {
	if c.ServiceName == "" {
		return fmt.Errorf("service name is required")
	}
	
	if c.Database.Password == "" && c.Environment.GetEnvironment() == "production" {
		return fmt.Errorf("database password required in production")
	}
	
	return nil
}

func main() {
	// Initialize configuration with defaults
	config := NewAppConfig()
	
	// Create flag configuration
	fc := flags.NewFlagConfig()
	
	// Add custom validation
	fc.AddValidator("ServiceName", func(value interface{}) error {
		if s, ok := value.(string); ok && len(s) < 3 {
			return fmt.Errorf("service name must be at least 3 characters")
		}
		return nil
	})
	
	// Mark required fields
	fc.SetRequired("ServiceName")
	
	// Register all configuration fields
	if err := fc.RegisterCustomTypes(config); err != nil {
		log.Fatalf("Failed to register configuration: %v", err)
	}
	
	// Parse command line arguments and environment variables
	if err := fc.Parse(os.Args[1:]); err != nil {
		log.Fatalf("Failed to parse configuration: %v", err)
	}
	
	// Validate the complete configuration
	if err := config.Validate(); err != nil {
		log.Fatalf("Invalid configuration: %v", err)
	}
	
	// Display final configuration
	fmt.Printf("=== Final Configuration ===\n")
	fmt.Printf("Service: %s\n", config.ServiceName)
	fmt.Printf("Environment: %s\n", config.Environment.GetEnvironment())
	fmt.Printf("Listen Address: %s\n", config.ListenAddr.String())
	fmt.Printf("Log Level: %s\n", config.LogLevel.GetLevel())
	fmt.Printf("Tags: %v\n", config.Tags)
	fmt.Printf("Timeouts: %v\n", config.Timeouts)
	fmt.Printf("Database: %s@%s:%d/%s\n", 
		config.Database.Username, 
		config.Database.Host, 
		config.Database.Port,
		config.Database.Database)
}

* Common Usage Patterns

** Pattern 1: Microservice Configuration
- Basic service identification (name, version, environment)
- Network configuration (listen address, external URL)
- Resource limits (timeouts, connections, workers)
- Feature flags (metrics, tracing, caching)
- Labels/metadata for service discovery

** Pattern 2: Database-Connected Service
- Database connection parameters (host, port, credentials)
- Connection pooling settings (max connections, timeouts)
- Migration and backup configurations
- Read/write splitting configuration

** Pattern 3: Multi-Environment Deployment
- Environment-specific defaults
- Conditional validation (stricter in production)
- Feature toggles per environment
- Security settings (TLS, allowed IPs, API keys)

** Pattern 4: Monitoring and Observability
- Metrics collection endpoints
- Log level configuration
- Tracing configuration
- Health check endpoints
- Alert thresholds and configurations

* Best Practices

** Configuration Structure
1. Group related settings into nested structs
2. Use meaningful default values
3. Provide clear usage descriptions
4. Implement validation for critical settings
5. Use appropriate types (time.Duration vs int, URL vs string)

** Environment Variables
1. Use UPPER_SNAKE_CASE consistently
2. Prefix with application name for isolation
3. Document all environment variables
4. Provide example .env files for each environment

** Validation
1. Validate early (at startup)
2. Provide helpful error messages
3. Use type-specific validation where possible
4. Implement cross-field validation when needed

** Security
1. Never log sensitive configuration values
2. Use separate credential management for secrets
3. Validate all network inputs (URLs, IP addresses)
4. Implement proper access controls for configuration
